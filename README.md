# ATOMIC STRUCTURE ↔ BITS · ASB

> A sphere of **UD0** — the ROOT0 universe / biosphere. Domain: **SCIENTIFIC**.

ATOMIC STRUCTURE ↔ BITS — the interactive canvas companion to [[the-atomic-byte]]: step through the elements (H→Kr) and watch an atom BUILD itself — nucleus, then electron shells filling one by one as Bohr rings (accurate aufbau occupancy: C=2,4 · Si=2,8,4 · Fe=2,8,14,2 · Kr=2,8,18,8) — while beside it the same structure renders as a REGISTER: each orbital type s/p/d/f/g is a byte, capacity 2·6·10·14·18 drawn as a binary word with bit 1 locked GOLD as the spin-seal, and a live dashed connector links the currently-filling shell to its byte row. Default element Silicon (the domain nod). Two-layer honest: the ring picture is a teaching simplification (real orbitals are probability clouds; Cr/Cu break the tidy filling order), what's REAL is 2n²/2l+1/spin/the capacities, and the bit analog is flagged a lens — 'atoms are binary' is only the trivial fact that every integer is a sum of powers of two. Slider + prev/next + play to watch the table fill. The atom, read two ways at once.
